# GRASS GIS Scripts — Topographic and Geophysical Mapping of the Peru-Chile Trench

GRASS GIS shell scripts used to produce the figures in the peer-reviewed article by Polina Lemenkova. The scripts map the topography, geophysics and terrain structure of the Peru-Chile (Atacama) Trench in the southeastern Pacific Ocean.

**Published in:** *Forum geografic* **2020**, *19*(2), 143–157
**DOI:** https://doi.org/10.5775/fg.2020.009.d
**Journal (open access):** http://forumgeografic.ro/2021/2704/
**HAL:** https://hal.science/hal-03155346
**Zenodo:** https://doi.org/10.5281/zenodo.4570553
**SSRN:** https://ssrn.com/abstract=3795477

## Contents
GRASS GIS shell scripts for topographic mapping, geoid undulations, free-air gravity and vertical gravity gradient, terrain derivatives (r.slope.aspect for slope, aspect, profile and tangential curvature), contouring (r.contour), raster patching/statistics (r.patch, r.colors.stddev) and vector geology overlay, with cartographic display via r.colors, d.rast, d.vect, d.legend, d.grid and d.text.
